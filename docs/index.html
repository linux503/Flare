为截图而生，也为录屏而来

少步骤、快反馈。从菜单栏到标注完成，尽量少点一次。

  • 区域 / 窗口 / 全屏

    拖选、取色放大镜、双击复制。选区工具栏一键编辑或钉图。

  • 屏幕录制

    ⌘⌥R 开始与停止，浮动计时条，导出 H.264 MOV。

    箭头、高亮、马赛克、序号；识字导出 TXT。

  • 历史与新建文档

    最近截图随时回看；一键新建 TXT / Word / PPT / Excel。
