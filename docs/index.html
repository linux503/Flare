截得快

菜单栏单击即进入区域截图，确认后直接编辑、复制、保存或钉图。

录得稳

改得顺

标注、OCR、历史记录串在同一条路径里，不必换工具。

功能

截图是一半，录屏是另一半

Flare Pro 把高频屏幕捕获收进一个 App：截图负责「瞬间」，录屏负责「过程」。

Screenshot

截图工作区

区域、窗口、全屏、延时四种方式。选区带放大镜与尺寸参考；确认后工具栏可直达编辑、复制、保存、OCR 或钉在桌面。

  • 默认快捷键 ⌘⌥5 区域截图
  • 右键菜单栏可进入更多截图方式
  • 历史记录保留最近截图，随时回看

Recording

录屏工作区

录制不再塞进截图菜单。顶部独立「录制」、主面板录制页、状态栏红点提示，开始 / 暂停 / 停止 / 丢弃路径清楚，导出 H.264 MOV。

  • 快捷键 ⌘⌥R 开始或停止
  • 倒计时、帧率、光标、排除 Flare 窗口
  • 录制中悬浮计时，状态栏可一键停止

Annotate

标注与识字

箭头、高亮、马赛克、序号等工具用于快速说明问题；OCR 可把图中文字导出为文本。截完就能改完，不用另开编辑器。

  • 编辑器内完成常用标注
  • OCR 导出 TXT
  • 钉图方便对照写文档

上手

三分钟就会用

01

授权屏幕录制

系统设置 → 隐私与安全性 → 屏幕与系统音频录制，打开 Flare Pro，然后完全退出再启动。

02

单击菜单栏截图

左键单击图标进入区域截图；右键打开完整菜单，可切到录屏、历史与设置。

03

需要时再录屏

用顶部「录制」菜单或 ⌘⌥R 开始。录完保存到录屏文件夹，或在录制面板调整选项。

菜单栏单击区域截图
⌘⌥5区域截图
⌘⌥R录屏开关
⌘O主面板
空格 / 回车确认选区
