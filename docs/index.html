上手

三步开始用

macOS 走系统授权；Windows 下 EXE、Android 下 APK 即可用网页长截图。

  1. 1

    授权

    macOS：系统设置 → 隐私与安全性 → 屏幕与系统音频录制，打开 Flare Pro，然后完全退出再打开。Windows / Android 无需此步骤，下载 EXE 或 APK 即可。

  2. 2

    截图

    单击菜单栏图标进入区域截图；右键可打开完整功能菜单。

  3. 3

    录屏

    用「录制」菜单或 ⌘⌥R。需要时再进主面板调整录制选项。
