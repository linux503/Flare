为 macOS 打造的原生工具。菜单栏单击截图，独立菜单录屏；标注、OCR、钉图与暂停倒计时，都在同一条工作流里。

产品能力

两件事做好：截图，和录屏

不是功能堆砌，而是把日常最高频的屏幕捕获路径收短：开始快、确认快、后续动作也顺手。

Screenshot

截图：点一下就开始

支持区域、窗口、全屏与延时。菜单栏图标单击直接进入区域截图；空格、回车或双击确认后，可立即编辑、复制、保存或钉在桌面。

  • 捕获方式区域 / 窗口 / 全屏 / 延时 3 秒
  • 选区体验取色放大镜、尺寸参考、工具栏快捷动作
  • 后续处理标注、OCR 识字、历史回看

Recording

录屏：独立菜单与面板

屏幕录制不再藏在截图里。顶部「录制」菜单、主面板录制页、状态栏红点提示，开始、暂停、停止、丢弃路径清晰，导出 H.264 MOV。

  • 录制控制开始 / 暂停继续 / 停止保存 / 丢弃
  • 录前选项倒计时、帧率、光标、排除本应用窗口
  • 录中反馈悬浮计时条、菜单栏状态、单击可停

Annotate & OCR

截完也能立刻改完

箭头、高亮、马赛克、序号等标注工具就在编辑器里；需要文字时一键 OCR 导出。历史记录保留最近截图，随时回看。

用法

少一步，就快一步

把最常用的动作放到最近的地方：图标、快捷键、菜单，三选一即可。

  1. 01

    开始

    单击菜单栏图标进入区域截图；或用「录制」菜单 / ⌘⌥R 开始录屏。

  2. 02

    完成

    框选后空格或回车确认；录屏中可暂停，结束时选择保存或丢弃。

  3. 03

    继续

    需要时进入标注与 OCR，或钉在桌面；也可用主面板管理历史与录制选项。

单击菜单栏区域截图
⌘⌥5区域截图（默认）
⌘⌥R开始 / 停止录屏
⌘O打开主面板

首次使用

  1. 打开「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」
  2. 勾选 Flare Pro（若有灰色旧条目，先删除再重新添加）
  3. 完全退出应用后重新打开

请从 /Applications/Flare Pro.app 运行，避免直接打开构建目录里的副本。
